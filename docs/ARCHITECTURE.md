# Архитектура

`plugin/main.py` — тонкий Decky RPC-адаптер. `plugin/backend/thorfg/` содержит
пути, проверку ELF/provenance, Steam VDF, TOML, транзакции, runtime и диагностику.
Frontend использует штатные Decky-компоненты для фокуса геймпада и сенсора.
Блокирующие операции выполняются в worker thread, изменения сериализованы.

Собственные настройки: `~/.config/thorfg/settings.json` (schema_version=1).
Runtime: `~/.local/share/thorfg/runtimes/<slot>/`.
Единственный управляемый manifest: пользовательский
`~/.local/share/vulkan/implicit_layer.d/ThorFG.json`.
Конфигурация upstream: `~/.config/lsfg-vk/conf.toml`; учитывается абсолютный
XDG_CONFIG_HOME. Внешний LSFGVK_CONFIG при записи блокирует применение.
Пути Decky берутся из его окружения, CLI использует текущего пользователя.

Настройки профиля хранятся и после выключения. В upstream активны только включённые
профили, имя `ThorFG:<appid>` отделяет владение. Неизвестные TOML-поля и комментарии
сохраняются tomlkit; строгая стабильная версия отвергает несовместимые поля до записи.
Переключение runtime глобальное: один loader не выбирает разные версии слоя по игре.
Поле runtime профиля должно соответствовать активному слоту.

Операция записывает резервные копии и журнал, затем атомарно заменяет файлы.
Перед каждой заменой сверяется исходное содержимое. Ошибка вызывает восстановление;
незавершённый журнал после остановки процесса блокирует новые записи до rollback.
Блокировка кооперативная: посторонний редактор её не соблюдает, поэтому остаётся
узкое окно гонки между проверкой и rename. Обнаружение другого менеджера блокирует запись.

Установщик принимает локальную директорию артефактов с build-report.json,
SHA-256, manifest и ELF. Файлы копируются в неизменяемый слот; существующий слот
не перезаписывается. Provenance связывает слот с одним из двух известных SHA upstream.
Это проверка целостности локальной сборки, не цифровая подпись издателя.
Обновление переключает только собственный manifest. Rollback восстанавливает журнал;
удаление не трогает чужие слои, игры или коммерческие DLL.

Диагностика разделяет «файлы проверены», «loader перечислил слой» и «процесс содержит
слой». Ни один из этих результатов не называется Hardware Verified.
Экспорт строится по разрешённым полям с обезличенными именами игр и путями;
произвольные логи, environment и cmdline в отчёт не включаются.
