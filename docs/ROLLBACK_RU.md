# Откат и удаление

Завершите игры. Откат восстанавливает **последнюю операцию**, а не абстрактную
«последнюю проверенную FG-конфигурацию»: аппаратно проверенных версий пока нет.
Каждая запись конфигурации/настроек, импорт/активация runtime и установка Decky-пакета
имеет снимок до изменения в `~/.config/thorfg/history/`.

**Терминал ArmadaOS, корень проекта:**

```bash
python3 scripts/thorfg.py rollback
```

Последовательные откаты возвращают операции в обратном порядке. Если после операции
файл изменило другое приложение, ThorFG остановится и не затрёт его. Восстановление
по незавершённому pending.json имеет приоритет над обычной историей.
В Decky есть та же команда с двухшаговым подтверждением.

Если процесс оборвался при удержании `write.lock`, сначала убедитесь, что ThorFG не работает
и выгрузите плагин. В Konsole проверьте, что каталог пуст, затем удалите только блокировку:

```bash
rmdir "${XDG_CONFIG_HOME:-$HOME/.config}/thorfg/write.lock"
```

Не удаляйте pending.json: он нужен для восстановления. После снятия устаревшей блокировки
повторите rollback. Копии содержат личные пути и настройки, не публикуйте их как диагностику.

## Снять регистрацию runtime

```bash
python3 scripts/thorfg.py uninstall
```

Удаляется только собственный `ThorFG.json`, наши профили выключаются, их настройки
остаются для будущего использования. Чужие профили и manifest не удаляются.
Если содержимое собственного manifest подменено, сначала сохраните его и разберите конфликт;
автоматическое удаление останавливается.

## Удалить только управляющий плагин

```bash
python3 scripts/decky_plugin.py uninstall
```

Удаляются только файлы, перечисленные в нашем manifest владения и не изменённые извне.
Пустые каталоги, Python cache и пользовательские файлы остаются. Чужие плагины не затрагиваются.
После этого перезагрузите список плагинов Decky либо устройство через меню Armada.
Сначала снимайте регистрацию runtime: удаление UI само по себе не отключает слой.

## Остаточные данные

Слоты runtime и история сохраняются намеренно. Если вы решите удалить их окончательно,
сначала убедитесь, что ни один manifest не ссылается на эти .so и games завершены,
затем удалите конкретный каталог ThorFG через файловый менеджер. Автоматического
рекурсивного удаления домашнего каталога или каталога lsfg-vk проект не выполняет.
