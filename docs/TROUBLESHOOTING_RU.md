# Диагностика

| Симптом | Что проверить |
|---|---|
| ThorFG отсутствует в Decky | Каталог homebrew, plugin.json, версия Decky, перезагрузка списка плагинов |
| Decky backend не ответил | Журнал ThorFG в интерфейсе Decky; наличие backend/ и py_modules/tomlkit в пакете |
| DLL не найдена | Собственная установка Lossless Scaling App ID 993090 во всех Steam libraries; для historical Lossless.dll, для stable lsfg-vk.dll |
| Неверная архитектура | file/readelf: ELF64, DYN, Machine AArch64; x86-64 .so не подходит host loader |
| Loader не перечислил слой | Диагностика вне Distrobox, абсолютный library_path, зависимости libc/libstdc++, видимость пользовательского implicit_layer.d |
| Слой есть только в gamescope | Проверить host/guest Vulkan путь конкретной игры через FEX/Proton; Game Mode и игра — разные процессы |
| Профиль сохранён, FG нет | Сверить фактический EXE и регистр, runtime slot, отсутствие env overrides и доступность DLL |
| Нет точного EXE в списке | Ввести реальный суффикс вручную, проверить maps/процессы; launcher может быть промежуточным |
| Конфликт менеджера | ArmadaLSFG и ThorFG не должны писать общий TOML одновременно; см. миграцию INSTALL_RU.md |
| Обнаружен MAKO/MangoHud/vkBasalt | ThorFG только сообщает о файлах; вручную исследовать совместимость, не удалять их автоматически |
| Операция незавершена | Сохранить pending.json, остановить плагин, выполнить rollback |
| Файл изменён извне | Не обходить проверку: сохранить обе версии, выяснить какой менеджер работает |
| Unknown | Нужный инструмент/данные недоступны; это не положительный результат проверки |

Первое действие — «Диагностика → Проверить Vulkan Loader», затем «Экспортировать отчёт».
Никаких переустановок ОС и прошивки загрузчика для диагностики не требуется.

Нестандартные XDG-каталоги поддерживаются только абсолютные и внутри home.
Символические ссылки/junction на путях записи блокируются. Steam-библиотеки на другой
карте читаются, но установщик не пишет туда. Если ~/.config — symlink, выберите обычный
пользовательский каталог и согласуйте XDG_CONFIG_HOME с Decky/Steam вручную.

В диагностический экспорт включён разрешённый набор технических полей, без сырых ошибок,
Steam-имён, конфигурации, окружения и журналов процессов. Подробные backend-ошибки
показываются локально; перед отправкой скриншотов/сырых логов проверьте их сами.
