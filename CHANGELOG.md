# Изменения

## Управление Decky через кнопки — 2026-10-15

* Все DropdownItem заменены ButtonItem: циклические раздел/язык/множитель,
  отдельный экран выбора игр, EXE и runtime с поиском и страницами по 20 вариантов.
* Добавлены React DOM-тесты нажатий и состояния, включая read-only и отсутствие
  сохранения/активации при выборе. Реальное управление на Thor проверяет владелец.

## Восстановление ARM64 runtime и диагностика — 2026-10-15

* LLVM ar/ranlib, отдельный build-llvm, явный resume и доверенное зеркало с commit/tree pin.
* Упаковка уже готовой сборки без сети/компиляции: schema 2 provenance, ELF, cache/log,
  подтверждение SHA, SHA256SUMS, совместимость со слотами и прежними bundle.
* Пассивная диагностика x86_64/i386/AArch64, отдельные изолированные host-load/loader/cube.
* Decky показывает build/bundle/slot/activation и причину read-only без ложного статуса FG.
* PowerShell SSH helper: обновление с backup/stash, упаковка build-llvm, доставка одного UI.
* Документированы переданные владельцем Thor результаты; настоящая FG ещё не проверена.

## Исправление CI 0.1.0-dev — 2026-10-15

* Изолированы HOME, USERPROFILE и XDG в тестовой fixture: mock Decky больше не использует
  каталоги реального GitHub runner. Добавлена отдельная CI-проверка загрязнённого окружения.
* Исправлена канонизация явно объявленного HOME alias для XDG/DECKY_HOME на Fedora-подобных
  системах; ссылки ниже HOME и посторонние alias по-прежнему запрещены.
* Добавлены 15 регрессионных тестов путей. Ошибки создания symlink в Linux больше
  не могут скрываться как skip; в Windows пропускается только отсутствие права symlink.
* Read-only сбор сведений расширен проверкой пользовательских путей и Steam libraries.
* Hardware Verified остаётся false; установка и активация runtime на Thor не выполнялись.

## 0.1.0-dev — 2026-10-15

* Создан отдельный управляющий проект ThorFG для первой цели AYN Thor Pro/ArmadaOS.
* Backend: Steam VDF, EXE, TOML round-trip, настройки профилей, журнал/rollback,
  безопасные пути, конфликт менеджеров, локальные слоты runtime, ELF/SHA/provenance.
* Decky UI: обзор, игры, диагностика, runtime; русская и английская локализация оболочки.
  Подробные сообщения backend пока на русском.
* Добавлены закреплённые рецепты исторического ARM64-кандидата и современной 2.0.0.
* Добавлены CLI-установщики, проверки и локальный пакет разработки без runtime/DLL.
* Проверка FG на Thor и публикация стабильного релиза ещё не выполнены.
